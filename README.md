# WPS 行情刷新脚本使用说明

适用于 WPS 在线表格的 AirScript。脚本文件：`行情刷新-整理版.js`。

## 一、安装和运行

1. 打开 WPS 在线表格和目标工作簿。
2. 打开“高级开发 → AirScript 脚本”。
3. 新建脚本，将 `行情刷新-整理版.js` 的全部内容复制进去并保存。
4. 点击运行。

脚本默认只更新名称为 **冲啊** 的 Sheet。当前停留在哪个 Sheet 不影响运行目标。

如果要换目标 Sheet，修改脚本顶部配置：

```js
targetSheet: '冲啊',
```

例如：

```js
targetSheet: '我的持仓',
```

Sheet 名称必须完全一致。

## 二、表格结构

第 1 行放表头，第 2 行开始放股票代码。表头顺序可以调整，脚本会按名称识别列。

推荐表头：

| 股票代码 | 股票名称 | 最新价 | 今日涨跌 | 昨日涨跌 | 涨跌额 | 今开 | 最高 | 最低 | 昨收 | 持仓数量 | 成本价 | 持仓市值 | 实时涨跌 | 浮动盈亏 | 持仓收益率 | 总浮动盈亏 | 当日总盈亏 | 更新时间 | 状态 |
|---|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---|---|
| 600519 | | | | | | | | | | 100 | 1500 | | | | | | | | |

股票代码支持：

- `600519`
- `sh600519`
- `000001`
- `sz000001`
- `510300`

对于 6 位纯数字代码，脚本会根据代码前缀自动判断沪市、深市或北交所。为避免 WPS 丢失前导零，深市代码建议写成 `sz000001`。

如果工作表完全为空，脚本会自动建立表头和 4 个示例代码。

## 三、持仓计算

持仓列是可选的。填写“持仓数量”和“成本价”后，脚本会自动计算：

```text
持仓市值 = 最新价 × 持仓数量
实时涨跌 / 当日盈亏 = 涨跌额 × 持仓数量
浮动盈亏 =（最新价 - 成本价）× 持仓数量
持仓收益率 =（最新价 - 成本价）÷ 成本价
```

“成本价”必须是每股单位成本，不是总投入金额。脚本不计算佣金、印花税、过户费等交易费用，因此这是未扣交易费用的浮动盈亏。

## 四、两个汇总列

如果表头包含：

- `总浮动盈亏`
- `当日总盈亏`

脚本会把合计写在表头正下方，也就是第一个股票数据行。下面的同列旧合计会自动清理。

```text
总浮动盈亏 = 所有有效持仓的浮动盈亏之和
当日总盈亏 = 所有有效持仓的当日盈亏之和
```

如果有持仓缺少有效报价、代码、成本价或涨跌额，对应汇总会留空，并在日志中提示，避免把不完整的合计误当作最终结果。

## 五、数据源顺序

实时行情按以下顺序自动补缺：

1. 东方财富 delay
2. 东方财富主站
3. 腾讯
4. 新浪
5. 同花顺逐只补齐

“昨日涨跌”默认使用腾讯历史 K 线，缺失时使用东方财富历史 K 线。数据源顺序由当前脚本固定，除非手动修改配置。

## 六、昨日涨跌缓存

同一个交易日内，“昨日涨跌”不会重复请求。缓存标记会明码写入第 1 行第 30 列，即 AD1，例如：

```text
昨日涨跌缓存:2026-09-07|12|a1b2c3d4
```

不要在 AD1 放其他内容。如果 AD1 已被占用，把配置中的 `yesterdayCacheCol: 30` 改成其他空列号。

代码或行号发生变化时，脚本会自动识别并重新获取相关历史数据。

## 七、显示设置

顶部配置可以调整：

```js
changeMode: 'percent', // percent、text、number
redGreen: false,       // true=涨红跌绿，false=统一黑色
timeToSecond: true     // 更新时间按文本写入，避免显示成序列号
```

金额会按原有逻辑四舍五入到两位，但不强制补末尾的 0。例如 `12.30` 可能显示为 `12.3`，实际数值仍为 `12.3`。

## 八、常见问题

### 1. 提示“找不到目标工作表”

检查 `targetSheet` 是否与 Sheet 名称完全一致，包括空格和标点。

### 2. 提示“找不到股票代码列”

第 1 行必须包含 `股票代码`、`代码` 或 `code` 其中一个表头。

### 3. 昨日涨跌获取很慢或为 0/部分

首次运行或新交易日需要逐只获取历史 K 线，可能比实时行情慢。接口限流时脚本会熔断，稍后再次运行即可；缓存不会记录失败结果。

### 4. 更新时间显示成 46269.xxxxx

使用当前整理版脚本，并保持 `timeToSecond: true`。脚本会先把更新时间列设为文本格式再写入。

### 5. 收益和同花顺相差少量金额

本脚本按“最新价、单位成本、持仓数量”计算，不包含交易费用，也可能与券商后台的隐藏成本精度不同。

## 九、运行日志

重点关注以下日志：

- `目标工作表`：确认更新的是哪个 Sheet。
- `行情获取`：确认实时行情成功数量。
- `昨日涨跌`：确认历史数据和缓存状态。
- `[耗时] 行情请求`：查看网络请求耗时。
- `普通字段批量写回`：确认表格写回是否使用批量区域。
- `完成：成功 ... 个`：确认最终更新数量。

## 十、验证范围

脚本已通过 JavaScript 语法检查、行情解析模拟、批量写回模拟、持仓汇总模拟和空数据场景检查。AirScript 的实际网络和 WPS 表格显示仍以 WPS 中运行结果为准。
